# Support

## Getting help with Local Memory Companion

Before opening a support request:

1. Read the README and troubleshooting section.
2. Confirm dependencies and the required runtime are installed.
3. Search existing issues for the same error.
4. Reproduce the problem with the smallest possible setup.

When opening an issue, include your operating system, runtime or engine version, exact command, expected result, actual result, and sanitized logs. Never include credentials or private data.
