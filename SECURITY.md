# Security Policy

## Supported versions

Security fixes are normally applied to the latest maintained version of Local Memory Companion.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in public issues.

Send the repository owner a private report containing:

- the affected component and version;
- reproduction steps or a minimal proof of concept;
- expected and observed behavior;
- impact and any known mitigation.

Remove credentials, personal information, and unrelated sensitive data from reports. The maintainer should acknowledge the report, investigate it, and coordinate remediation and disclosure when appropriate.
